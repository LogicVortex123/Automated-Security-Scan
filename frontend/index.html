LibreHealth EHR Workflows

Automated Security Scan Dashboard

Clean local demo for simulated vulnerability assessment and trend tracking.

Overview

Select a healthcare module, run a simulated security scan, and review module posture, latest findings, and historical trend.

This is a demo workflow with predefined patterns. No file upload is required.

Flow

  1. Pick modulePatient Registration, Lab Results, Billing, or Appointment Scheduling.
  2. Run scanCalls POST /security-check and stores the result.
  3. Review outputCards + posture + trend from latest and recent scans.
  4. Export reportDownload printable HTML report for submission.

Connection help (only if API is not reachable)

No MongoDB. This app uses SQLite (automatic) or optional MySQL only. Nothing to paste except the PHP server URL below if needed.

Recommended: run php -S localhost:8000 router.php in the project folder, then open http://localhost:8000/ (or double-click start-server.bat).
